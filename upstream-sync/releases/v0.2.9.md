  add the upstream client-disconnect exit after the scheduling-result stage.

  thread, parent-thread, and client-request identity headers.

  combine channel reasoning maps with the upstream image-price override helper.
  An unset image price now inherits catalog pricing, while explicit zero remains
  an override. Remove the superseded image-input-only helper.

  upstream passthrough-discovery and Google-concurrency tests.
- Add the new client-closed telemetry tests without reintroducing older ops
  tests removed from the product branch before this release.
- Content-audit implementation, route registration, plugin account scopes,
  database schema, migrations, and dependency lockfiles are unchanged by this
  merge. The gateway route match in the audit report concerns request forwarding;
  it introduces no new route or moderation bypass.
