The initial diagnosis treated all compile failures as stale tests. Inspection of
existing callers, configuration, frontend types and the original commits showed
that several production implementations had been omitted during earlier merges.
This follow-up corrects that diagnosis and repairs those paths:

- Restore the existing opt-in simple-mode API-key spending windows from
  3b336b2ec, retaining request deduplication and excluding balance, subscription,
  lifetime-key, account and platform charges.

  contract from fc96132e7. Keep nullable decimal strings, invalidate missing
  balances as unknown, and update the snapshot after quota reset.
- Complete API-key-only compatible Gemini image forwarding from 0dd71286f,
  including composite multipart aliases and channel-mapped capability selection.
- Complete the existing c4c2e6607 model-pricing integration: dedicated GPT-6
  Sol/Luna and Opus 5.5 fallback entries, explicit zero cache-write prices,
  context thresholds and Fast pricing across 5m/1h cache creation.
- Keep the product's Fable 5.1 max reasoning multiplier at 3x, and make its
  account-cost test assert that contract explicitly.
- Update plugin tests to pass the current account scope and enabled bindings;
  remove use of the superseded scoped-directory wrapper. Apply the shared
  global outbound identity policy to plugin-resolved credentials.
- Update repository and image-route fixtures for the current gateway constructor;
  run the image end-to-end fixture through the registered moderation pipeline.
