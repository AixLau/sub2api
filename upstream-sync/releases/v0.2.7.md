# Upstream Integration: v0.2.7

- Upstream tag: `v0.2.7` (`aea725f2ea644d5592d0bbb1d63b607efa7e200a`).
- Previous selected upstream release: `v0.2.5` (`86f93c28ee34cc74b629dafb748bd5ac5ca8c5ea`).
- Product parent: `6cca33bc6`.

## Merge boundary

Earlier release integrations copied selected upstream changes without adding the
upstream commits as merge parents. Replaying from the historical Git merge base
would undo reviewed local product decisions and repeat already integrated work.
This merge therefore applies the complete v0.2.5-to-v0.2.7 delta by three-way
patch merge and records v0.2.7 as its second parent. Earlier selection boundaries
remain as documented in the corresponding release records. Future merges can
use the v0.2.7 merge ancestor directly.

## Integration decisions

- Seedance native task creation, polling and cancellation share the existing
  media ownership, concurrency and billing path. Creation uses local content
  moderation; all four URL aliases are registered in the coverage manifest.
- The generalized media account selector replaces the Grok-only wrapper while
  retaining sticky ownership checks and user-scoped scheduler admission.
- Plugin host key-value storage, account directory and passive status APIs are
  integrated with the local account allowlist. Wire connects both the manager
  and gateway before startup, and the application starts the manager's existing
  reconciliation lifecycle.
- Local Codex metadata, user-agent, egress environment and moderation policy
  customizations are retained.
- Frontend fixes retain local BaseDialog rendering, the registration layout,
  monitor provider catalog and the four-worker proxy test queue. Batch proxy
  tests now reuse the upstream duplicate-request guard.
- The OpenCode billing regression exposed by focused tests is fixed: Claude
  fallback candidates require explicit group/channel pricing, matching the
  existing local regression contract.
- Redemption history uses one paginated response contract, including requests
  without query parameters. The upstream legacy-array branch and retired
  service method are removed; the API contract test uses the new shape.
- Dependency upgrades follow the upstream delta; Wire output is regenerated.
  No Ent schemas or database migrations change in this release delta.
