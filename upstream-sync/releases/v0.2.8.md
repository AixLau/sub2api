## Integration boundary

The v0.2.7-to-v0.2.8 delta was applied on top of the product branch while
recording `v0.2.8` as the second parent. The release adds OpenCode Go usage
windows, referral and affiliate withdrawal flows, account quota UI, backup and
risk-control improvements, model/catalog updates, reasoning-effort pricing,
release tooling, and the associated migrations and tests.

The upstream content-moderation-engine migration and its new engine implementation
were excluded because they replace the product fork's established moderation
interfaces and conflict with local keyword, semantic-review, incremental-cache,
account-scope, and batch-image moderation contracts. Existing local moderation
code remains the source of truth; the exclusion is deliberate and recorded here.

The local Codex identity/session graph, plugin binding scope, OpenAI user-agent
policy, public-transit behavior, and other product-specific gateway contracts were
retained while incorporating compatible upstream additions. Wire was regenerated
against the resulting provider set. Small compatibility shims retain local
interfaces where upstream v0.2.8 changed helper names or pricing fields.
