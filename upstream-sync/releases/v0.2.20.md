# Upstream v0.2.20

- Previous selected upstream release: `v0.2.19` (`dece26153621959ccd7635814f4b2d08304e681a`).
- Upstream commit: `dab829a4e9b7d1cc307189aea8b0319eb29e29d0`.
- Product merge commit: recorded after the merge commit is created.

Integrated the v0.2.20 upstream release, including the OAuth-authenticated
management MCP and its consent UI, request body read timeouts and memory
budgets with 408/499 classification, downstream write timeouts, OpenAI image
size-tier (1K/2K/4K) account routing, GPT Image 2.6, the GPT-6.1 Terra official
Codex descriptor, cyber transcript length-aware matching (#8519), registration
email blacklist, scoped admin key permission and statistics updates,
Antigravity quota summaries and connection-test prompts, error passthrough
rules overriding the built-in 413 mapping, OpenAI transport-error cooldown
switch, Codex export defaults (GPT-6.1 Sol, live web search, API-key auth with
image extension), and vue-i18n v11.

Local behavior retained during conflict resolution:

- Pre-forward pipeline (moderation registrar snapshots, routing/forward/usage
  stages) stays the single path; upstream body-read classification
  (`handleRequestBodyReadError` / `requestBodyReadFailure`) is applied inside
  it, and local ops diagnostics are kept via `requestBodyReadFailureWithOps`.
- `ReadRequestBodyWithLimit` / lenient JSON reads keep the local limit on both
  compressed and decompressed size, now implemented on the upstream budgeted
  reader (`readRequestBodyWithBudgetLimit`).
- Image size-tier routing is carried by the routing stage (`ImageSize`) for
  `/v1/images` and image-intent `/v1/responses`; size passes keep the local
  per-user cooldown argument.
- Local client-message localization, API key auth diagnostics, rate-limit
  dimension (global vs per-IP with upstream IPv6 prefix bucketing), drainable
  HTTP handler (kept outermost around upstream read/write timeouts), reward
  routes/handler wiring, Codex client config cache injection, cyber block key
  carry-over, 7d auto-reset credit policy (no upstream `ResetCreditTargeted` /
  `CacheCreditsSnapshot`), quota-API usage refresh instead of synthetic probes,
  and CC Switch TOML imports with local long-context settings.
- Upstream scoped-admin access checks were added to the retained local quota
  and usage-refresh paths.

Fixes applied during the merge:

- Restored the GPT Image 2.5/2.6 image cache-read fallback price dropped by the
  textual merge.
- Usage tasks in Grok media and alpha search no longer read `gin.Context`
  inside the async closure (upstream boundary test).
