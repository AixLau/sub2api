星链 AI Hub · 客户端接入指南

把 Codex 和 Claude Code 接到 星链 AI Hub

两种配置方式任选其一：一键脚本 自动写入本地配置（推荐），CC Switch 可视化管理多份配置。下面分步带你走完，傻瓜式按图操作即可。

1

登录 星链 AI Hub 创建 API Key

访问 https://aixlau.me 登录后进入「API 密钥」页面，点击「创建密钥」。命名随意，能识别用途即可（例如 mac-codex），并选择「按量计费」或「订阅」分组。

在「API 密钥」页面创建一个新的密钥。
提示：密钥创建好后，点击它右侧的复制按钮即可复制完整密钥，下一步会用到。
2

打开终端

在 macOS 上按 ⌘ + 空格 调出 Spotlight，输入 Terminal 回车即可打开终端。Linux 用户用任意终端模拟器都行。

3

粘贴并运行下面的命令

把整行命令复制到终端按回车。脚本会自动下载安装程序，并在过程中提示你输入第 1 步创建的 API Key。

curl -fsSL https://aixlau.me/install/bootstrap.sh | bash
提示：粘贴 Key 时终端不会显示出来，是正常的，输入完直接回车即可。
4

选择客户端并粘贴 API Key

按下面两步操作：

  1. 用 ↑ ↓ 选择要配置的客户端（默认已选中 Codex），按 回车 确认；
  2. 看到「请输入你的 API Key」时，粘贴第 1 步复制的密钥后回车（粘贴时不会显示出来，是正常的）。
用上下键选中 Codex，回车后粘贴 API Key。

回车后脚本会自动备份原配置并写入新配置，看到写入成功的提示就完成了。整个过程只配置你选中的那一个客户端，不会动其他客户端。

会写入哪些文件：选 Codex 写入 ~/.codex/config.toml 和 ~/.codex/auth.json；选 Claude Code 写入 ~/.claude/settings.json。如果文件已存在会先自动备份，可放心运行。
5

重启客户端开始使用

关闭并重新打开你刚配置的那个客户端，让它读取新配置即可：

  • Codex APP（桌面客户端）：直接退出后重新打开应用即可；
  • Codex CLI：终端里重新执行 codex 启动；
  • Claude Code：终端里重新执行 claude 启动，会自动走 星链 AI Hub 网关。
1

登录 星链 AI Hub 创建 API Key

访问 https://aixlau.me 登录后进入「API 密钥」页面，点击「创建密钥」。命名建议带平台标识，例如 win-codex，并选择「按量计费」或「订阅」分组。

在「API 密钥」页面创建一个新的密钥。
提示：密钥创建好后，点击它右侧的复制按钮即可复制完整密钥，下一步会用到。
2

打开 PowerShell

按 Win 键，输入 PowerShell，在搜索结果里点击 Windows PowerShell 或 PowerShell 7。普通用户权限即可，无需用管理员模式打开。

3

粘贴并运行下面的命令

把命令整段复制到 PowerShell 里按回车。脚本会自动下载安装程序，然后先让你选择客户端，再提示输入第 1 步创建的 API Key。

irm "https://aixlau.me/install/bootstrap.ps1?v=20260618-encoding" | iex
提示：粘贴 Key 时 PowerShell 不会显示出来，是正常的，输入完直接回车即可。
如果提示"无法加载脚本 / 执行策略"被拦住：复制下面这条等效命令再跑一次即可（只对本次有效，不改你电脑的全局设置）。 
powershell -ExecutionPolicy Bypass -Command "irm 'https://aixlau.me/install/bootstrap.ps1?v=20260618-encoding' | iex"
4

选择客户端并粘贴 API Key

按下面两步操作：

  1. 用 ↑ ↓ 选择要配置的客户端（默认已选中 Codex），按 回车 确认；
  2. 看到「请输入你的 API Key」时，粘贴第 1 步复制的密钥后回车（粘贴时不会显示出来，是正常的）。
用上下键选中 Codex，回车后粘贴 API Key。

回车后脚本会自动备份原配置并写入新配置，看到写入成功的提示就完成了。整个过程只配置你选中的那一个客户端，不会动其他客户端。

会写入哪些文件：选 Codex 写入 %USERPROFILE%\.codex\config.toml 和 %USERPROFILE%\.codex\auth.json；选 Claude Code 写入 %USERPROFILE%\.claude\settings.json。如果文件已存在会先自动备份，可放心运行。
5

重启客户端开始使用

关闭并重新打开你刚配置的那个客户端，让它读取新配置：

  • Codex APP（桌面客户端）：需要彻底退出后再重新打开，详见下方提醒；
  • Codex CLI：在 PowerShell 里重新执行 codex 启动；
  • Claude Code：重新执行 claude 启动，会自动走 星链 AI Hub 网关。
Windows 上 Codex APP 要彻底退出才会生效：直接点右上角的 × 只是最小化到右下角的系统托盘，程序其实还在运行，配置不会重新加载。请在右下角任务栏托盘区（必要时点 ∧ 展开隐藏图标）找到 Codex 图标，右键它 →「退出 / Quit」，再重新打开应用。
在右下角托盘区右键 Codex 图标，点「退出」彻底关闭后再重新打开。
找不到命令？可能是 Codex / Claude Code 还没装。先去各自官方下载安装客户端，再重新执行本脚本。

常见问题

Q：跑脚本前我需要装什么？

macOS 自带 curl 和 bash，不需要额外装。Windows 用 PowerShell 5.1 及以上即可（Win10/11 自带）。Codex 和 Claude Code 客户端要自己装好，脚本只负责写配置文件。

Q：脚本会把我原来的配置覆盖掉吗？

不会丢。每个被改动的文件都会先备份成 xxx.bak.YYYYMMDD-HHMMSS 留在原目录，需要回退直接把 .bak.* 改回原名即可。

Q：换了新 Key 怎么办？

重新跑一遍同样的命令，输入新 Key 即可，旧的会自动覆盖。

Q：想恢复成官方 Codex/Claude？

把对应的备份文件 .bak.* 改回原文件名，或直接删掉脚本生成的配置块（config.toml 里有 # BEGIN SUB2API MANAGED BLOCK 标记区段）。

1

下载并安装 CC Switch

CC Switch 用来在多个服务商和账号之间快速切换，适合同时配多套环境的用户。

  • 官方文档：ccswitch.io/zh/docs
  • Windows：CC-Switch-v3.15.0-Windows.msi
  • macOS：CC-Switch-v3.15.0-macOS.dmg
2

在 星链 AI Hub 创建 API Key

登录 https://aixlau.me 后进入「API 密钥」页面，点击「创建密钥」，名称按用途填即可。

API 密钥页面入口。
3

确认计费分组和账号来源

创建密钥时选择需要使用的计费分组。自定义密钥可以按自己的规则填写；不填写时系统会随机生成。

  • 计费分组决定走哪个模型平台、价格倍率和可用账号池。
  • 「我的账号」里加了自有账号的话，可以优先用它，通常网络更稳定。
  • 自有账号额度不足时，按系统配置回退到平台账号。
创建密钥时选择计费分组和密钥配置。
4

一键导入到 CC Switch

密钥创建完成后，在密钥列表点击「导入到 CCS」。浏览器会调起 ccswitch:// 协议，把当前 API Key、服务地址、客户端类型一次写进 CC Switch。

在密钥列表点击「导入到 CCS」。
CC Switch 收到配置后确认保存。
5

切换配置并重启 Codex / Claude Code

在 CC Switch 中切到刚导入的配置，然后重启对应客户端。重启是为了让客户端读取新写入的配置文件。

选择刚导入的配置并应用。
6

验证登录状态

客户端重启后，看到 API Key 登录状态就说明已经接入成功。后续切换服务商，只需要在 CC Switch 里切配置 + 重启客户端。

Codex 已通过 API Key 方式登录。
导入按钮没反应？大概率是 CC Switch 还没装好，或系统没注册 ccswitch:// 协议处理。重新安装 CC Switch 后再点一次即可。
