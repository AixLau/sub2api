星链AI · ChatGPT 安装与 API 中转接入指南

ChatGPT 安装与 Codex API 中转配置教程

需要桌面应用时，可先在 macOS 或 Windows 安装 ChatGPT；随后把 Codex、Codex CLI 或 Claude Code 接入星链AI。可任选 一键脚本 自动写入本地配置（推荐），CC Switch 可视化管理多份 API 中转配置。Codex 支持应用增强模式：接入第三方 API 的同时，保留官方插件、手机远程操作等 Codex APP 能力。

1

登录 星链 AI Hub

访问 https://aixlau.me 注册并登录即可。后续脚本会打开浏览器完成一次性授权，系统会自动创建 API Key 并写入本机配置，不需要你手动创建或复制密钥。

提示：如果浏览器里还没登录，授权页会先引导你登录。
2

打开终端

在 macOS 上按 ⌘ + 空格 调出 Spotlight，输入 Terminal 回车即可打开终端。Ubuntu 用户也可以按 Ctrl + Alt + T；其他 Linux 用户从应用菜单中搜索「Terminal」或「终端」。

3

安装 ChatGPT（仅 macOS）

如果已经安装 ChatGPT，可以跳过这一步。macOS 用户运行下面的独立安装命令，脚本会下载 OpenAI 官方最新 DMG、校验安装包并自动打开：

curl -fsSL https://aixlau.me/install/install-chatgpt.sh | bash
  1. 等待下载和校验完成，安装包会自动打开；
  2. 按照 macOS 安装窗口提示，将 ChatGPT 拖入「Applications / 应用程序」文件夹；
  3. 从「应用程序」中打开 ChatGPT。
Linux 用户：OpenAI 当前没有提供 Linux 桌面安装包，请跳过这一步，继续配置 Codex CLI 或 Claude Code。也可以使用 ChatGPT 网页版。
4

粘贴并运行下面的命令

先点击命令右上角的「复制」按钮，再回到终端窗口粘贴：macOS 按 ⌘ + V，Linux 通常按 Ctrl + Shift + V。看到命令出现在终端后按回车。该命令会下载最新配置脚本，然后打开浏览器完成授权；授权完成后会自动创建 API Key 并写入本机配置。

curl -fsSL https://aixlau.me/install/bootstrap.sh | bash
提示：如果浏览器没有自动打开，终端里会显示一个链接和验证码。复制链接到浏览器打开，使用刚才登录的同一个账号完成授权；授权过程中不要关闭终端。
5

选择客户端并等待自动授权

按下面两步操作。终端会显示客户端列表，其中一行会有高亮背景：

  1. 用 ↑ ↓ 移动高亮，选中要配置的客户端（默认已选中 Codex），按 回车 确认；
  2. 浏览器打开授权页后，使用刚才登录的同一个账号完成授权；如果出现「允许」「授权」或「继续」，按页面提示点击。不要关闭终端，页面会自动创建 API Key 并把结果交回终端。
用上下键选中 Codex，回车后浏览器会自动完成授权并创建 API Key。

回车后脚本会自动备份原配置并写入新配置，看到写入成功的提示就完成了。整个过程只配置你选中的那一个客户端，不会动其他客户端。

会写入哪些文件：选 Codex 写入 ~/.codex/ 下的相关文件；选 Claude Code 写入 ~/.claude/settings.json。如果文件已存在会先自动备份，可放心运行。
6

重启客户端开始使用

关闭并重新打开你刚配置的那个客户端，让它读取新配置即可：

  • Codex APP（桌面客户端）：直接退出后重新打开应用即可；
  • Codex CLI：终端里重新执行 codex 启动；
  • Claude Code：终端里重新执行 claude 启动，会自动走 星链 AI Hub 网关。
Codex APP 增强：选择 Codex 时，脚本会保留 Codex 应用增强能力；使用星链 AI Hub 第三方 API 的同时，仍可继续使用官方插件、手机远程操作等功能。
1

登录 星链 AI Hub

访问 https://aixlau.me 注册并登录即可。后续脚本会打开浏览器完成一次性授权，系统会自动创建 API Key 并写入本机配置，不需要你手动创建或复制密钥。

提示：如果浏览器里还没登录，授权页会先引导你登录。
2

打开 PowerShell

先按一下键盘左下角带 Windows 图标的 Win 键。开始菜单出现后，不用找输入框，也不用点击任何位置，直接用键盘输入 PowerShell，系统就会自动搜索。然后在搜索结果里点击 Windows PowerShell 或 PowerShell 7。 普通用户权限即可，无需用管理员模式打开。

3

安装 ChatGPT

如果已经安装 ChatGPT，可以跳过这一步。在 PowerShell 中运行下面的独立安装命令，它会打开微软商店的 ChatGPT 官方页面：

powershell -ExecutionPolicy Bypass -Command "irm 'https://aixlau.me/install/install-chatgpt.ps1' | iex"
  1. 微软商店打开后，确认页面中的应用名称为 ChatGPT；
  2. 点击「获取」或「安装」，等待安装完成；
  3. 点击「打开」，或稍后从开始菜单启动 ChatGPT。
微软商店没有打开？请访问 OpenAI 官方下载页面，再选择 Windows 下载入口。
4

粘贴并运行下面的命令

先点击命令右上角的「复制」按钮，再回到 PowerShell 窗口按 Ctrl + V 粘贴，看到命令出现在窗口后按回车。如果 Ctrl + V 没反应，在 PowerShell 窗口内点击鼠标右键也可以粘贴。该命令会下载最新配置脚本，然后先让你选择客户端，再打开浏览器自动授权并创建 API Key。

powershell -ExecutionPolicy Bypass -Command "irm 'https://aixlau.me/install/bootstrap.ps1' | iex"
提示：如果浏览器没有自动打开，PowerShell 里会显示一个链接和验证码。复制链接到浏览器打开，使用刚才登录的同一个账号完成授权；授权过程中不要关闭 PowerShell。
5

按下面两步操作。PowerShell 会显示客户端列表，其中一行会有高亮背景：

  1. 用 ↑ ↓ 移动高亮，选中要配置的客户端（默认已选中 Codex），按 回车 确认；
  2. 浏览器打开授权页后，使用刚才登录的同一个账号完成授权；如果出现「允许」「授权」或「继续」，按页面提示点击。不要关闭 PowerShell，页面会自动创建 API Key 并把结果交回 PowerShell。
用上下键选中 Codex，回车后浏览器会自动完成授权并创建 API Key。

回车后脚本会自动备份原配置并写入新配置，看到写入成功的提示就完成了。整个过程只配置你选中的那一个客户端，不会动其他客户端。

6

重启客户端开始使用

关闭并重新打开你刚配置的那个客户端，让它读取新配置：

  • Codex APP（桌面客户端）：需要彻底退出后再重新打开，详见下方提醒；
  • Codex CLI：在 PowerShell 里重新执行 codex 启动；
  • Claude Code：重新执行 claude 启动，会自动走 星链 AI Hub 网关。
Codex APP 增强：选择 Codex 时，脚本会保留 Codex 应用增强能力；使用星链 AI Hub 第三方 API 的同时，仍可继续使用官方插件、手机远程操作等功能。
Windows 上 Codex APP 要彻底退出才会生效：直接点右上角的 × 只是最小化到右下角的系统托盘，程序其实还在运行，配置不会重新加载。请在右下角任务栏托盘区（必要时点 ∧ 展开隐藏图标）找到 Codex 图标，右键它 →「退出 / Quit」，再重新打开应用。
在右下角托盘区右键 Codex 图标，点「退出」彻底关闭后再重新打开。
找不到命令？ChatGPT 桌面端可按第 3 步安装；Codex CLI 或 Claude Code 命令行客户端需要先按各自官方说明安装，再重新执行配置脚本。
!

运行脚本后，Codex 仍显示「登录 ChatGPT」怎么办？

看到这个页面时，不要点「继续登录」，请点「使用其他方式登录」。
  1. 点击 「使用其他方式登录」，选择使用 API Key 登录；
  2. 回到 星链 AI Hub 的「API 密钥」页面，找到脚本自动创建的 codex 密钥；
  3. 点击下图黑色箭头指向的复制图标，复制这条密钥；
  4. 返回 Codex，把密钥粘贴到 API Key 输入框，再点「继续」；
  5. 进入 Codex 后即可使用。后续正常退出、重新打开，不需要重复输入。
黑色箭头指向的就是复制按钮，点击后再返回 Codex 粘贴密钥。
注意：API Key 相当于账号密码，只粘贴到 Codex 登录框，不要发给其他人。如果页面里没有 codex 密钥，请重新运行一键脚本并完成浏览器授权。
OpenAI 官方也说明桌面端可在退出登录页面选择其他登录方式并输入 API Key。详见 Codex 身份验证说明。

常见问题

Q：Codex API 中转站怎么配置？

登录星链AI 后，在 macOS、Linux 或 Windows 上运行本页的一键脚本，选择 Codex 并完成浏览器授权。脚本会自动创建 API Key、备份旧配置并写入 API 中转配置；也可以切换到 CC Switch 教程手动添加供应商。

Q：Claude Code 如何接入 API 中转服务？

运行一键脚本时选择 Claude Code，完成浏览器授权后，脚本会备份并更新 Claude Code 配置。重新执行 claude 启动即可使用。

Q：跑脚本前我需要装什么？

macOS 自带 curl 和 bash，Windows 10/11 自带 PowerShell。ChatGPT 桌面端可直接使用本页第 3 步安装；Codex CLI 和 Claude Code 命令行客户端仍需按各自官方说明安装。

Q：ChatGPT 桌面端怎么安装？

macOS 在终端运行本页安装命令，脚本会下载、校验并打开 OpenAI 官方 DMG；Windows 在 PowerShell 运行安装命令，脚本会打开微软商店的 ChatGPT 页面。Linux 当前没有官方桌面安装包。

Q：脚本会把我原来的配置覆盖掉吗？

不会丢。每个被改动的文件都会先备份成 xxx.bak.YYYYMMDD-HHMMSS 留在原目录，需要回退直接把 .bak.* 改回原名即可。

Q：我还需要自己创建 API Key 吗？

不需要。普通一键脚本流程只要求你注册并登录 星链 AI Hub，脚本会自动创建一个专用 API Key 并写入本机配置。

Q：脚本完成后打开 Codex，为什么还是「登录 ChatGPT」页面？

这是桌面端的首次登录确认，不是脚本失败。点「使用其他方式登录」→ 使用 API Key，再到 星链 AI Hub 的「API 密钥」页面复制脚本自动创建的 codex 密钥并粘贴即可。

Q：想恢复成官方 Codex/Claude？

把对应的备份文件 .bak.* 改回原文件名，或直接删掉脚本生成的配置块（config.toml 里有 # BEGIN SUB2API MANAGED BLOCK 标记区段）。

1

下载并安装 CC Switch

CC Switch 用来在多个服务商和账号之间快速切换，适合同时配多套环境的用户。

  • 官方文档：ccswitch.io/zh/docs
  • Windows：CC-Switch-v3.17.0-Windows.msi
  • macOS：CC-Switch-v3.17.0-macOS.dmg

Windows 安装：点击上面的 Windows 链接下载 .msi 文件。下载完成后双击文件，按照安装窗口的提示点击「下一步」完成安装，然后打开 CC Switch。

macOS 安装：点击上面的 macOS 链接下载 .dmg 文件。下载完成后双击文件，把 CC Switch 图标拖进「Applications / 应用程序」文件夹，再从「应用程序」中打开 CC Switch。

macOS 提示无法打开？进入「系统设置 → 隐私与安全性」，在页面下方找到 CC Switch，点击「仍要打开」。
2

在星链 AI Hub 创建 API Key

登录 https://aixlau.me 后进入「API 密钥」页面，点击「创建密钥」。名称按用途填写（例如 codex），选择可用的 Codex 分组后点击「创建」，其他限制按需设置。

填写密钥名称并选择 Codex 分组，其余选项可保持默认。
3

优先一键导入到 CC Switch

密钥创建完成后，在密钥列表右侧点击「导入到 CCS」。系统会根据当前 Codex 分组生成配置并尝试唤起 CC Switch，自动写入 API Key 和服务地址。

  • 浏览器询问是否打开 CC Switch 时，请选择允许。
  • CC Switch 打开后确认导入，随后启用新导入的供应商。
点击密钥右侧的「导入到 CCS」，即可尝试自动导入。
一键导入可能会受系统协议关联影响。如果点击后没有打开 CC Switch、提示协议未注册，或导入后配置不可用，请继续按下面的步骤手动添加。
4

一键导入失败时，先复制 API Key

回到星链 AI Hub 的「API 密钥」页面，点击密钥右侧的复制图标，把完整 API Key 复制到剪贴板。不要使用页面中经过隐藏的缩略文本。

黄色箭头所示为复制按钮；黑色箭头所示仍可再次尝试一键导入。
5

在 CC Switch 新增 Codex 供应商

打开 CC Switch，先切换到顶部的 Codex 页面，再点击右上角的「+」添加供应商。

选择 Codex，然后点击右上角的「+」。
6

选择自定义配置

在「添加新供应商」页面选择「自定义配置」。预设供应商不包含星链 AI Hub，因此需要手动填写必要字段。

在预设供应商列表中选择「自定义配置」。
7

填写配置并启用

按下面的内容填写，完成后点击右下角「添加」：

  • 供应商名称：填写 星链，或使用其他容易识别的名称。
  • API Key：粘贴第 4 步复制的完整密钥。
  • API 请求地址：只填写 https://aixlau.me，末尾不要添加 /v1 或其他路径。
  • 完整 URL：保持关闭；高级选项无需修改。
填写供应商名称、API Key 和 API 请求地址后添加。

点击「添加」后，CC Switch 通常会自动回到 Codex 供应商列表；如果仍停留在当前页面，点击左上角的返回箭头。找到刚创建的「星链」，点击它右侧的启用按钮或开关，确认「星链」显示为当前正在使用的供应商。和使用一键脚本配置后一样，这里也必须完全退出并重启 Codex，否则 Codex 仍会继续使用旧配置。

  • macOS：在 Codex 中按 Command + Q 完全退出，再重新打开 Codex。
  • Windows：在右下角系统托盘找到 Codex 图标，右键选择「退出 / Quit」，再重新打开 Codex。只点击窗口右上角的 × 不算完全退出。

重启后，在 Codex 中发送一句简单的测试消息。能够正常收到回复，就表示 CC Switch 配置已经生效。

请保护好 API Key。它相当于账号密码，只应粘贴到你自己的 CC Switch 中，不要发送给其他人。
