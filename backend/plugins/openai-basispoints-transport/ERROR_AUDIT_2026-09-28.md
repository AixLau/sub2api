## 本次根因修复

1. **反馈读取丢失错误。** 原实现对 HTTP 非 2xx 只记录状态、对 SSE error 只返回通用字符串，再统一改成 TOOL_BRIDGE_CALL_INVALID。现在以终结失败快照保留结构化上游错误、已知状态和安全的重试/限流响应头。非结构化代理错误保留 HTTP 状态，不泄露任意代理正文。
2. **强制要求 completed，覆盖真实终结原因。** 反馈返回 failed / incomplete 时原实现直接抛出“未生成 completed”。现在保留上游 error / incomplete_details、初始响应身份和累计 usage，且不会发布失败批次里的任何可执行工具调用。
3. **失败终结仍使用成功批次校验。** 流式失败快照可以合法省略未完成工具；原实现可能先报“遗漏工具调用”。完整批次一致性检查现在只适用于 completed，真实终结状态和错误优先保留。
4. **空输出结构。** 无可见输出的失败结果统一为 output: []，避免 nil 切片编码成 null。

两条生产反馈失败记录已经丢失具体续接错误，不能事后断言它们一定是限流。代码缺陷通过本地定向回归重现，并覆盖 HTTP 429/5xx、嵌套和扁平 SSE error、failed/incomplete、截断、取消、重复标识和未执行工具隔离。
